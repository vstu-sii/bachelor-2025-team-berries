# Use-case Narrative: Просмотр конкретного продукта

## 1. Краткое описание
Пользователь просматривает детальную информацию по конкретному товару, включая историю анализов, текущую статистику отзывов, графики и ключевые метрики.

## 2. Участники (Actors)
- **Пользователь:** Аутентифицированный пользователь с доступом к товару
- **Система хранения данных:** База данных товаров и истории анализов
- **Визуализатор данных:** Система генерации графиков и диаграмм

## 3. Pre-conditions
- Пользователь аутентифицирован в системе
- Пользователь имеет как минимум один проанализированный товар
- Пользователь находится в разделе "Мои товары"
- Выбранный товар существует и имеет данные анализов

## 4. Post-conditions
- **Успех:** Пользователь видит детальную страницу товара со всей историей анализов и статистикой
- **Неудача:** Пользователь видит сообщение об ошибке загрузки данных товара

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь нажимает на иконку товара в разделе "Мои товары" | Система определяет ID выбранного товара |
| 2 | ... | Система загружает детальную страницу товара с индикатором загрузки |
| 4 | ... | Система отображает основную информацию: название, изображение, ссылку на маркетплейс, общий рейтинг |
| 7 | ... | Система показывает блок "История анализов" с предыдущими анализами |
| 8 | Пользователь выбирает конкретный анализ для просмотра | Система отображает выбранный анализ |

**Ценность для пользователя:**
- **Глубокий анализ:** Полное понимание динамики отзывов и ключевых проблем товара
- **Визуальное представление:** Интуитивно понятные графики и диаграммы для быстрого анализа

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Просмотр товара с одной историей анализа
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь выбирает товар с единственным анализом | Система загружает данные товара |
| 2 | ... | Система определяет, что доступен только один анализ |
| 3 | ... | В блоке "История анализов" система показывает: "Это первый анализ товара" |
| 4 | ... | Сравнения с предыдущими периодами не доступно |
| 5 | ... | Система предлагает: "Запустите новый анализ для отслеживания динамики" |

**Ценность для пользователя:**
- **Понятный интерфейс:** Ясное указание на ограничения данных
- **Мотивация к действию:** Стимулирование регулярного обновления анализов

#### A.2: Просмотр товара с длинной историей анализов
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь выбирает товар с 10+ анализами | Система загружает полную историю |
| 2 | ... | Система показывает компактный список последних 5 анализов |
| 3 | ... | Предоставляется "Показать всю историю" для раскрытия полного списка |
| 4 | Пользователь нажимает "Показать всю историю" | Система отображает полный хронологический список всех анализов |

**Ценность для пользователя:**
- **Управление сложностью:** Постепенное раскрытие информации без перегрузки интерфейса
- **Быстрый доступ:** Эффективная навигация по большому объему исторических данных

### 5.3. Error Handling (Обработка ошибок)

#### E.1: Товар не найден или удален
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь нажимает на товар | Система не находит товар в базе данных |
| 2 | ... | Система возвращает ошибку |
| 3 | ... | Система показывает сообщение: "Товар не найден. Возможно, он был удален." |
| 4 | ... | Система предлагает "Вернуться к моим товарам" |
| 5 | Пользователь нажимает "Вернуться к моим товарам" | Система возвращает в раздел "Мои товары" |


**Ценность для пользователя:**
- **Грейсфул деградейшн:** Сохранение функциональности даже при частичных сбоях
- **Альтернативное представление:** Доступ к данным в любом случае

    O -->|Альтернативное отображение| I
    Q -->|Показ ошибки| I
