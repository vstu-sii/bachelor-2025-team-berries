# Use-case Narrative: Сравнить выбранные анализы

## 1. Краткое описание
Пользователь, находясь на странице товара, выбирает несколько предыдущих анализов из истории и запускает их сравнение. Система генерирует сводный отчет, визуализирующий ключевые метрики и динамику изменений между выбранными периодами.

## 2. Участники (Actors)
- **Пользователь:** Аутентифицированный пользователь, владелец товара
- **Система управления данными:** Хранение и предоставление истории анализов
- **Визуализатор данных:** Система генерации сравнительных графиков и диаграмм
- **ИИ-анализатор (опционально):** ML-модель для генерации текстовых инсайтов на основе сравнения

## 3. Pre-conditions
- Пользователь аутентифицирован и находится на странице конкретного товара
- Товар имеет как минимум два завершенных анализа в истории
- Выбранные анализы имеют корректные данные для сравнения

## 4. Post-conditions
- **Успех:** Пользователь видит сводный отчет сравнения выбранных анализов с графиками и ключевыми инсайтами
- **Неудача:** Пользователь получает сообщение об ошибке с объяснением причины

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь на странице товара видит блок "История анализов" | Система отображает список предыдущих анализов |
| 2 | Пользователь отмечает 2-3 анализов для сравнения | Система визуально подсвечивает выбранные анализы и активирует "Сравнить выбранное" |
| 3 | Пользователь нажимает "Сравнить выбранное" | Система открывает новую страницу/ окно сравнения |
| 4 | | Система загружает данные выбранных анализов и генерирует сравнительный отчет |
| 5 | | Система отображает: <br> - Сравнительную таблицу ключевых метрик (рейтинг, кол-во отзывов, тональность) <br> - Накопительные графики изменения рейтинга во времени <br> - Круговые диаграммы распределения тональности для каждого периода <br> - Список ключевых аспектов, которые улучшились или ухудшились |

**Ценность для пользователя:**
- **Выявление трендов:** Четкое понимание динамики ключевых показателей товара во времени
- **Объективная оценка:** Возможность оценить эффективность изменений товара или маркетинговых активностей

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Сравнение только двух анализов

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь выбирает ровно два анализа для сравнения | Система активирует сравнения |
| 2 | Пользователь запускает сравнение | Система генерирует отчет с акцентом на прямое сравнение "до/после" |
| 3 | | Система подсвечивает изменения в ключевых метриках |

**Ценность для пользователя:**
- **Фокус на изменениях:** Максимально сконцентрированный отчет о том, что именно изменилось между двумя точками
- **Автоматизированные инсайты:** Готовая аналитика без необходимости самостоятельного анализа графиков

#### A.2: Выбор максимального количества анализов (5+)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь пытается выбрать более 5 анализов | Система показывает предупреждение: "Для лучшей читаемости рекомендуется сравнивать не более 5 анализов одновременно." |
| 2 | | Система ограничивает выбор 5 анализами, автоматически снимая предыдущие отметки |
| 3 | Пользователь подтверждает выбор из 5 анализов | Система генерирует отчет с упором на общие тренды и агрегированные данные |

**Ценность для пользователя:**
- **Сбалансированная визуализация:** Предотвращение перегруженного и нечитаемого интерфейса
- **Фокус на главном:** Выявление долгосрочных трендов вместо мелких колебаний

### 5.3. Error Handling (Обработка ошибок)

#### E.1: Выбран только один анализ

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь отмечает только один анализ и нажимает "Сравнить" | Система проверяет количество выбранных анализов |
| 2 | | Система блокирует запуск и показывает сообщение: "Для сравнения необходимо выбрать как минимум два анализа." |
| 3 | | Кнопка "Сравнить" остается неактивной до выбора второго анализа |

**Ценность для пользователя:**
- **Предотвращение ошибок:** Четкое руководство к действию для получения meaningful результата
- **Интуитивный интерфейс:** Система предотвращает бессмысленные операции

#### E.2: Данные одного из анализов повреждены

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь запускает сравнение нескольких анализов | Система обнаруживает, что данные одного анализа некорректны или отсутствуют |
| 2 | | Система показывает предупреждение: "Данные анализа повреждены." |


**Ценность для пользователя:**
- **Отказоустойчивость:** Проблемы с частью данных не блокируют всю функциональность
- **Прозрачность:** Пользователь информирован о любых исключениях из запрошенного отчета
