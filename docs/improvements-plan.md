## 1. Список доработок
- Интеграционные тесты для проверки end‑to‑end сценариев (UC1–UC6).
- Юнит‑тесты для ключевых функций (анализ тональности, выявление проблем, генерация рекомендаций).
- UX‑улучшения: удобный просмотр аналитики, оптимизация форм подключения маркетплейсов, улучшение визуализации отчетов.

---

## 2. Приоритизация задач

| Задача | Приоритет | Комментарий |
|--------|-----------|-------------|
| Интеграционные тесты | P1 | Критично для подтверждения DoD и защиты |
| Юнит‑тесты | P1 | Обеспечивают надёжность и покрытие функций |
| UX‑улучшения аналитики | P2 | Повышают ценность продукта для бизнес-пользователей |
| Оптимизация скорости сбора данных | P2 | Улучшает пользовательский опыт при работе с большими объемами |

---

## 3. Распределение по ролям

| Роль | Ответственность |
|------|-----------------|
| **System Architect (SA)** | Проверить достижение целей из Лабы 1, проанализировать результаты тестирования, скорректировать требования и подготовить план доработок для финального спринта |
| **Fullstack Developer** | Провести комплексное UX‑тестирование интерфейса, тестирование API endpoints, исправить все найденные баги и оптимизировать пользовательский опыт |
| **MLops Engineer** | Финализировать CI/CD pipeline с полными качественными гейтами, настроить мониторинг для AI-моделей, провести нагрузочное тестирование и оптимизировать производительность |
| **AI Engineer** | Провести оценку качества NLP-моделей (точность, recall), оптимизировать промпты для анализа тональности, доработать алгоритмы выявления проблем и подготовить итоговый отчёт |

---

## 4. Выводы
- Все критические задачи (тесты) будут закрыты до Demo Day.
- UX‑улучшения выполняются параллельно и усиливают ценность продукта для бизнес-пользователей.
- Команда готова к финальной защите проекта.
