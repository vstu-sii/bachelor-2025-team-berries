# Use-case Narrative: Первый анализ (добавление нового продукта)

**Author**: Alexandra 
**Date**: 20.09.2025  
**Version**: 2.0

## 1. Краткое описание

Пользователь впервые добавляет товар для анализа путем ввода ссылки на карточку товара с маркетплейса. Система парсит отзывы, анализирует их с помощью ИИ и сохраняет результат в профиле пользователя.

## 2. Участники (Actors)

- **Пользователь**: Аутентифицированный пользователь, добавляющий первый товар
- **Парсер маркетплейса**: Система сбора данных с маркетплейсов
- **ИИ-анализатор**: ML-модель для анализа тональности и аспектов отзывов
- **База данных**: Система хранения результатов анализа

## 3. Pre-conditions

- Пользователь аутентифицирован и находится в личном кабинете на главной станице
- Пользователь имеет корректную ссылку на товар с поддерживаемого маркетплейса
- Система парсера и ИИ-анализатора доступны и функционируют

## 4. Post-conditions

- **Успех**: Товар добавлен в "Мои товары", проведен анализ, пользователь видит детальный отчет
- **Неудача**: Пользователь получает сообщение об ошибке 

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь на главной странице видит поле для ввода ссылки и кнопку "Начать анализ" | ... |
| 2 | Пользователь копирует и вставляет ссылку на товар с маркетплейса (например, Wildberries) | ... |
| 3 | Пользователь нажимает кнопку "Начать анализ" | Система показывает индикатор прогресса |
| 4 | ... | Система парсит страницу товара, извлекает все доступные отзывы и метаданные товара |
| 5 | ... | ИИ-модель анализирует отзывы: определяет тональность и ключевые аспекты (качество, доставка, упаковка и т.д.) |
| 6 | ... | Система агрегирует результаты: подсчитывает общую статистику, строит графики распределения |
| 7 | ... | Система сохраняет товар и результаты анализа в базе данных, связывая с пользователем |
| 8 | ... | Система добавляет иконку товара в раздел "Мои товары" с краткой оценкой |
| 9 | ... | Система открывает детальную страницу отчета по проанализированному товару |

**Ценность для пользователя:**

- **Быстрый старт**: Процесс добавления первого товара интуитивно понятен и занимает минимум времени
- **Комплексный анализ**: Получение готовой аналитики без необходимости ручной обработки данных
- **Визуализация результатов**: Наглядное представление данных в виде графиков и диаграмм

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Товар с большим количеством отзывов (>1000)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь добавляет товар с большим количеством отзывов | Парсер определяет количество отзывов (>1000) |
| 2 | ... | Система показывает предупреждение: "Обнаружено большое количество отзывов. Анализ может занять больше времни. Продолжить?" |
| 3 | Пользователь подтверждает анализ | Система запускает фоновую задачу, пользователь может продолжать работу |
| 4 | ... | По завершении система отправляет push-уведомление и обновляет раздел "Мои товары" |

**Ценность для пользователя:**

- **Неблокирующая работа**: Возможность продолжать использование системы во время длительного анализа
- **Своевременное уведомление**: Пользователь не пропускает готовность результатов

#### A.2: Товар уже существует у пользователя

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь вводит ссылку на товар, который уже анализировался ранее | Система проверяет дубликаты |
| 2 | ... | Система обнаруживает существующий товар и показывает сообщение: "Этот товар уже есть в вашем кабинете. Хотите обновить анализ?" |
| 3 | Пользователь подтверждает обновление | Система запускает новый анализ |


**Ценность для пользователя:**

- **Предотвращение дублирования**: Избежание бесполезного повторного анализа одного товара
- **История изменений**: Возможность отслеживать динамику отзывов over time

### 5.3. Error Handling (Обработка ошибок)

#### E.1: Некорректная или неподдерживаемая ссылка

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь вводит неподдерживаемую ссылку (например, YouTube) | ... |
| 2 | ... | Система подсвечивает поле ввода красным и показывает сообщение: "Этот маркетплейс пока не поддерживается. Доступны: Wildberries" |

**Ценность для пользователя:**

- **Мгновенная обратная связь**: Немедленное понимание ошибки без ожидания обработки
- **Обучение**: Понятное объяснение, какие маркетплейсы поддерживаются

#### E.2: Товар не найден или отсутствуют отзывы

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь вводит корректную ссылку, но товар не существует | Система возвращает ошибку |
| 2 | ... | Система анализирует ответ парсера и определяет отсутствие данных |
| 3 | ... | Система показывает сообщение: "Товар не найден или на него пока нет отзывов. Проверьте ссылку и попробуйте позже." |

**Ценность для пользователя:**

- **Точная диагностика**: Четкое указание на причину проблемы
- **Рекомендации**: Конкретные советы по решению проблемы

#### E.3: Превышение лимитов парсера

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь запускает анализ | Система возвращает ошибку (Too Many Requests) от маркетплейса |
| 2 | ... | Система обрабатывает ошибку и показывает сообщение: "Маркетплейс временно ограничил запросы. Попробуйте через 10-15 минут." |

**Ценность для пользователя:**

- **Понимание ограничений**: Ясное объяснение технических ограничений работы с маркетплейсами
