# Use-case Narrative: Просмотр ранее проанализированных продуктов

## 1. Краткое описание
Пользователь просматривает список всех ранее проанализированных товаров в разделе "Мои товары". Каждый товар представлен в виде иконки с краткой информацией о последнем анализе.

## 2. Участники (Actors)
- **Пользователь:** Аутентифицированный пользователь с историей анализов
- **Система хранения данных:** База данных товаров и результатов анализа

## 3. Pre-conditions
- Пользователь аутентифицирован в системе
- Пользователь имеет как минимум один проанализированный товар
- Пользователь находится в личном кабинете

## 4. Post-conditions
- **Успех:** Пользователь видит полный список своих товаров с актуальной информацией
- **Неудача:** Пользователь видит сообщение об ошибке загрузки данных

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь заходит в личный кабинет | Система автоматически загружает раздел "Мои товары" |
| 2 | ... | Система отображает товары с основной информацией: название, изображение, рейтинг, дата последнего анализа |
| 3 | Пользователь просматривает список товаров | Каждая иконка товара содержит: <br> - Изображение товара <br> - Короткое название (обрезанное) <br> - Общий рейтинг (звезды/смайлы) <br> - Дата последнего анализа <br> - Индикатор изменения рейтинга (↑/↓) |

**Ценность для пользователя:**
- **Быстрый обзор:** Мгновенное понимание состояния всех отслеживаемых товаров
- **Визуальная навигация:** Интуитивно понятное представление большого количества товаров
- **Эффективный поиск:** Быстрый доступ к нужному товару через фильтры и поиск

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Пользователь имеет много товаров (>50)
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь с большой коллекцией товаров открывает раздел | Система загружает первые 10 товаров |
| 2 | ... | Система показывает индикатор "Загружено 10 из ... товаров" и "Загрузить еще" |
| 3 | Пользователь прокручивает вниз или нажимает "Загрузить еще" | Система подгружает следующие 10 товаров без перезагрузки страницы |

**Ценность для пользователя:**
- **Оптимизация производительности:** Быстрая загрузка интерфейса даже при большом количестве данных
- **Постепенная загрузка:** Возможность работать с уже загруженными данными, не дожидаясь полной загрузки

#### A.2: Пользователь не имеет товаров (первый вход)
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Новый пользователь заходит в раздел "Мои товары" | Система определяет отсутствие товаров в профиле |
| 2 | ... | Вместо товаров система показывает приветственный экран: "У вас пока нет товаров для анализа" |
| 3 | ... | Система предлагает "Добавить первый товар" |
| 4 | Пользователь нажимает "Добавить первый товар" | Система перенаправляет на главную страницу для добавления нового товара |

**Ценность для пользователя:**
- **Беспрепятственный переход:** Быстрый доступ к функции добавления товара

### 5.3. Error Handling (Обработка ошибок)

#### E.1: Проблемы с загрузкой данных
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь открывает раздел "Мои товары" | Система временно недоступен или возвращает ошибку |
| 2 | ... | Система показывает сообщение: "Не удалось загрузить список товаров. Пожалуйста, попробуйте позже." |
| 3 | ... | Система предлагает кнопку "Повторить загрузку" |
| 4 | Пользователь нажимает "Повторить загрузку" | Система повторяет загрузку |

**Ценность для пользователя:**
- **Стабильность работы:** Система корректно обрабатывает временные сбои
- **Простое восстановление:** Легкий способ повторить операцию при возникновении проблем

#### E.2: Проблемы с отображением изображений товаров
| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь просматривает список товаров | Некоторые изображения товаров не загружаются |
| 2 | ... | Система автоматически заменяет битые изображения на иконку |
| 3 | ... | Основная информация о товаре (название, рейтинг) остается доступной |

**Ценность для пользователя:**
- **Непрерывность работы:** Проблемы с изображениями не блокируют доступ к основной информации
- **Корректное отображение:** Интерфейс сохраняет целостность даже при частичных сбоях
