# Use-case Narrative: Регистрация и вход через Telegram

**Author**: Alexandra
**Date**: 20.09.2025  
**Version**: 2.0

## 1. Краткое описание

Пользователь заходит на сайт и может войти в систему или зарегистрироваться с помощью Telegram аккаунта через Telegram Widget. После успешной аутентификации пользователь получает доступ к личному кабинету с функционалом анализа товаров.

## 2. Участники (Actors)

- **Пользователь**: Новый или существующий пользователь, имеющий аккаунт в Telegram
- **Telegram Auth System**: Внешняя система аутентификации Telegram
- **Система анализа отзывов**: Наша платформа

## 3. Pre-conditions

- Пользователь имеет установленное приложение Telegram на устройстве
- Пользователь имеет активный аккаунт Telegram
- Telegram Widget доступен и функционирует нормально
- Пользователь имеет стабильное интернет соединение
- Пользователь находится на главной странице сайта
- Пользователь еще не зарегистрирован или не зашёл в свой аккаунт

## 4. Post-conditions

- **Успех**: Пользователь аутентифицирован в системе, создан/обновлен профиль, открыт личный кабинет
- **Неудача**: Пользователь остается на главной странице без доступа к функциям анализа

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь находится на главной странице сайта | Система отображает главную страницу с кнопками "Войти через Telegram" и "Регистрация через Telegram" |
| 2 | Пользователь нажимает кнопку "Войти через Telegram" | Система отображает Telegram Widget для авторизации |
| 3 | Пользователь вводит свои данные Telegram в виджет и подтверждает вход | Telegram Widget возвращает данные пользователя (id) |
| 4 | ... | Система проверяет существование пользователя с таким Telegram ID в базе данных |
| 5 | ... | Если пользователь существует, система обновляет последний вход и открывает личный кабинет |
| 6 | ... | Если пользователь новый, система создает запись в базе данных с полученными данными Telegram |
| 7 | ... | Система создает сессию и JWT-токен для пользователя |
| 8 | ... | Система перенаправляет пользователя в личный кабинет с доступом ко всем функциям |

**Ценность для пользователя:**

- Мгновенный доступ: Регистрация и вход происходят в 1-2 клика без заполнения форм
- Безопасность: Использование защищенной аутентификации через Telegram
- Удобство: Не требуется запоминать пароли или подтверждать email

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Первая регистрация нового пользователя

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Новый пользователь нажимает "Регистрация через Telegram" | Система отображает Telegram Widget |
| 2 | Пользователь подтверждает авторизацию | Система получает данные Telegram |
| 3 | ... | Система определяет, что пользователь новый, и создает аккаунт |
| 4 | ... | Система открывает личный кабинет |

**Ценность для пользователя:**

- Беспрепятственный старт: Минимальные действия для начала работы с системой

#### A.2: Пользователь возвращается после перерыва

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь заходит на сайт с того же устройства | Система проверяет наличие активной сессии |
| 2 | ... | Если сессия активна, система автоматически перенаправляет в личный кабинет |
| 3 | ... | Если сессия истекла, но есть refresh token, система автоматически обновляет сессию |
| 4 | Пользователь видит личный кабинет | Все данные и история анализов сохранены |

**Ценность для пользователя:**

- Непрерывность работы: Автоматический вход сохраняет рабочий процесс
- Сохранение контекста: Все предыдущие анализы и настройки доступны сразу

### 5.3. Error Handling (Обработка ошибок)

#### E.1: Telegram Widget недоступен

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь нажимает кнопку входа | Telegram Widget не загружается (таймаут или ошибка сети) |
| 2 | ... | Система обнаруживает ошибку загрузки виджета |
| 3 | ... | Система показывает сообщение: "Telegram временно недоступен. Пожалуйста, попробуйте позже." |

**Ценность для пользователя:**

- Понятная обратная связь: Пользователь понимает причину проблемы

#### E.2: Пользователь отменяет авторизацию в Telegram

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь открывает Telegram Widget | Виджет запрашивает разрешение на авторизацию |
| 2 | Пользователь нажимает "Отмена" в Telegram | Telegram возвращает ошибку отмены авторизации |
| 3 | ... | Система обрабатывает ошибку и показывает сообщение: "Авторизация отменена. Для использования системы требуется войти через Telegram." |
| 4 | ... | Система возвращает пользователя на главную страницу |

**Ценность для пользователя:**

- Уважение выбора: Система не навязывает авторизацию
- Ясность: Понятное сообщение объясняет необходимость входа
