# **Приоритизация задач AI Review Analyzer (MVP Scope)**

## 1. **Определение MVP**
**MVP включает 5 ключевых use‑cases:**

### ✅ Выполненные Use‑cases:
- **UC1** — Регистрация и вход через Telegram (пока тг не раб, только регестрация)
- **UC2** — Вход через Telegram  (пока тг не раб, только вход)
- **UC3** — Выход из системы
- **UC6** — Просмотр конкретного продукта 

### ❌ Не выполненные Use‑cases:
- **UC4** — Первый анализ (добавление нового продукта) — интерфейс готов; LLM и парсер отзывов работают изолировано (нет интеграции с бекендом)
- **UC5** — Просмотр ранее проанализированных продуктов - интерфейс готов; LLM и парсер отзывов работают изолировано (нет интеграции с бекендом)
- **U7** — Запустить новый анализ по датам - не реализовано
- **U8** — Сравнить выбранные анализы - не реализовано
**Итог:** Из 8 use‑cases полностью работают только 4, остальные имеют только интерфейс без функционала.
