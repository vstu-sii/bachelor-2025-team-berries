# **Приоритизация задач AI Review Analyzer (MVP Scope)**

## 1. **Определение MVP**
**MVP включает 6 ключевых use‑cases:**
- **UC1** — Регистрация и вход 
- **UC2** — Выход из системы
- **UC3** — Просмотр конкретного продукта 
- **UC4** — Первый анализ (добавление нового продукта) 
- **UC5** — Просмотр ранее проанализированных продуктов 
- **U6** — Запустить повторный анализ 
  
**Итог:** все use‑cases реализованы, end‑to‑end сценарий работает.

## 2. **Приоритизация backlog**

- Все задачи MVP выполнены.  
- Backlog состоит из улучшений:  
  - безопасность (хэширование паролей, токены),  
  - автоматизация (тесты, CI/CD),  
  - оптимизация производительности,  
  - UX‑улучшения.
