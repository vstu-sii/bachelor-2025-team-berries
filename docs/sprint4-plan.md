## План Спринта — Product Reviews Analysis System

## MLOPS (Infrastructure/ML Pipeline)
1. Развернуть рабочий LLM-сервис (Ollama/Mistral) и интегрировать в существующий стек
2. Контейнеризовать существующий ML preprocessing код
3. Настроить мониторинг запросов к LLM (через существующие Prometheus/Grafana)
4. Подготовить инструкции по запуску LLM-сервиса вместе с основной системой

## AI ENGINEER (ML/LLM Integration)
1. Интегрировать подготовленные промпты с развернутым LLM-сервисом
2. Настроить пайплайн: сырые отзывы → preprocessing → LLM → структурированный результат
3. Протестировать качество анализа на тестовых данных
4. Создать эндпоинт для проверки работы LLM-сервиса
5. Реализовать парсер Wildberries и подключить к Express.js бэкенду

## FULLSTACK ENGINEER (Integration & Features)
1. Создать эндпоинты для запуска анализа: `/api/analyze`, `/api/reviews`
2. Подключить LLM-сервис к бэкенду для обработки собранных отзывов
3. Активировать существующий интерфейс анализа
4. Реализовать сохранение результатов анализа в БД и отображение в интерфейсе
5. Добавить базовые графики на страницу товара

## Приоритизация задач

1. **Реализация парсера Wildberries** — без данных работа системы невозможна
2. **Интеграция LLM-сервиса** — без анализа нет основного функционала
3. **Создание эндпоинтов анализа в Express.js** — `/api/analyze`, `/api/reviews`
4. **Связка парсера с LLM** — полный пайплайн обработки отзывов
5. **Активация интерфейса анализа** — подключение фронтенда к новым эндпоинтам
6. **Сохранение и отображение результатов** — вывод структурированного отчета в UI
7. **Базовая визуализация** — простые графики распределения тональности
8. **Обработка ошибок** — валидация входных данных и понятные сообщения
9. **Оптимизация производительности** — кеширование, оптимизация LLM-запросов
10. **Расширенная аналитика** — сравнение периодов, тренды
11. **Детальные графики** — интерактивная визуализация
12. **Расширенный мониторинг** — детальные метрики качества анализа

## Roadmap до завершения MVP

**Спринт 1 (1 неделя): Рабочее ядро**
- Развертывание LLM-сервиса
- Реализация парсера Wildberries
- Создание эндпоинтов для запуска анализа в Express.js

**Спринт 2 (1 неделя): Интеграция и активация**
- Подключение фронтенда к новым эндпоинтам анализа
- Активация кнопок "Анализировать" и "Показать отчет"
- Базовая визуализация результатов (текстовый отчет + простые графики)
- Обработка ошибок и валидация входных данных

**Спринт 3 (1-2 недели): Стабилизация и подготовка**
- Тестирование полного цикла работы
- Оптимизация производительности парсера и LLM-запросов
- Создание демо-сценариев и документации
- Финальная проверка всех компонентов

## Критерии завершения MVP:
- Регистрация и вход через Telegram
- Архитектура двух сервисов (Core Service + Consumer Service)
- Добавление товара по ссылке на Wildberries
- Парсинг отзывов,их анализ и генерация рекомендаций  через LLM API
- Личный кабинет с разделом "История анализов"
- Детальная страница анализа с рекомендациями и статистикой
