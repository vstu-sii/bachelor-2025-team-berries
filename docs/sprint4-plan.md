## План Спринта 4 — Product Reviews Analysis System

## MLOPS (Docker/Infrastructure)
1. Настройка рабочего LLM сервиса в Docker (Mistral/Ollama)
2. Интеграция ML контейнеров в существующий docker-compose
3. Настройка метрик ML моделей в Prometheus/Grafana
4. Оптимизация Docker образов (multi-stage builds)
5. Написание инструкции по развертыванию ML компонентов
6. Unit и integration тесты для ML пайплайна

## AI ENGINEER (LLM/ML)
1. Интеграция существующего preprocessing кода с LLM моделями
2. Создание и тестирование промптов для анализа тональности
3. Сбор метрик качества анализа (Accuracy, F1-score)
4. А/B тестирование разных подходов к анализу отзывов

## FULLSTACK ENGINEER (Backend + Frontend)
1. Реализация аутентификации через Telegram
2. Создание эндпоинтов FastAPI для работы с ML пайплайном
3. Разработка фронтенда (React) 
4. Интеграция Frontend ↔ Backend API
5. Реализация базовых use-cases (добавление товара, просмотр отчетов)
6. Обработка ошибок и валидация входных данных
7. Создание интерфейса для визуализации аналитики
8. Парсинг данных с Wildberries

## Приоритизация задач
1. **P0:** Контейнеризация и интеграция ML пайплайна
2. **P0:** Создание рабочего LLM сервиса в Docker
3. **P0:** Реализация базовых эндпоинтов API для анализа
4. **P1:** Аутентификация через Telegram
5. **P1:** Минимальный фронтенд для демонстрации
6. **P2:** Парсинг данных с Wildberries
7. **P2:** Визуализация аналитики и графиков

## Технический долг
1. **Критический:** Отсутствие интеграции между компонентами
2. **Высокий:** ML код не контейнеризирован
3. **Высокий:** Нет работающего LLM сервиса
4. **Средний:** Отсутствие фронтенда
5. **Средний:** Нет аутентификации
6. **Низкий:** Непроверенная производительность системы

## Планирование улучшений
1. Уточнить OpenAPI спецификацию на основе реальной реализации
2. Добавить инструкции по запуску полной системы через docker-compose

## Roadmap до Demo Day

**Недели 1-2: Работающий прототип**
- Контейнеризация и интеграция ML пайплайна
- Рабочий LLM сервис для анализа тональности
- Базовые API эндпоинты для анализа отзывов
- Минимальный фронтенд для демонстрации

**Недели 3-4: Базовый функционал**
- Аутентификация через Telegram
- Парсинг данных с Wildberries (или mock-реализация)
- Сохранение результатов в БД
- Визуализация базовой аналитики

**Недели 5-6: Улучшение и стабилизация**
- Оптимизация производительности ML пайплайна
- Расширенная визуализация (графики, диаграммы)
- Обработка ошибок и валидация данных
- Интеграционное тестирование

**Недели 7-8: Подготовка к демо**
- Настройка полного CI/CD пайплайна
- Документация и инструкции по запуску

- Финальное тестирование и отладка
