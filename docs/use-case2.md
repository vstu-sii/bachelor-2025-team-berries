# Use-case Narrative: Выход из системы

**Author**: Alexandra
**Date**: 20.09.2025  
**Version**: 2.0

## 1. Краткое описание

Аутентифицированный пользователь выходит из системы, завершая текущую сессию. После выхода пользователь перенаправляется на главную страницу и теряет доступ к функциям личного кабинета.

## 2. Участники (Actors)

- **Пользователь**: Аутентифицированный пользователь системы
- **Система аутентификации**: Менеджер сессий и JWT токенов

## 3. Pre-conditions

- Пользователь аутентифицирован в системе
- Пользователь находится в личном кабинете
- Активная сессия пользователя существует

## 4. Post-conditions

- **Успех**: Сессия пользователя завершена, токены удалены, пользователь перенаправлен на главную страницу
- **Неудача**: Сессия остается активной, пользователь остается в личном кабинете

## 5. Детальные сценарии

### 5.1. Happy Path (Основной успешный сценарий)

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь нажимает на аватар или меню профиля в правом верхнем углу | Система отображает выпадающее меню с опциями профиля |
| 2 | Пользователь выбирает пункт "Выйти" из меню | Система показывает диалог подтверждения: "Вы уверены, что хотите выйти?" |
| 3 | Пользователь подтверждает выход нажатием "Да" | ... |
| 4 | ... | Система перенаправляет пользователя на главную страницу |

**Ценность для пользователя:**

- **Безопасность**: Гарантированное завершение сессии защищает аккаунт от несанкционированного доступа
- **Удобство**: Простой и понятный процесс выхода
- **Конфиденциальность**: Быстрая возможность выйти с общедоступного устройства

### 5.2. Alternative Flows (Альтернативные сценарии)

#### A.1: Пользователь отменяет выход

| Шаг | Действие Пользователя | Ответ Системы |
|-----|----------------------|---------------|
| 1 | Пользователь нажимает "Выйти" в меню профиля | Система показывает диалог подтверждения |
| 2 | Пользователь нажимает "Отмена" в диалоге подтверждения | Система закрывает диалог без выполнения выхода |
| 3 | ... | Пользователь остается в личном кабинете, сессия активна |

**Ценность для пользователя:**

- **Предотвращение ошибок**: Снижение риска случайного выхода из системы
- **Контроль**: Пользователь полностью управляет процессом выхода
