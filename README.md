## Описание проекта


AI Review Analyzer автоматически собирает и анализирует отзывы с маркетплейсов, определяет тональность, выделяет ключевые проблемы и генерирует рекомендации по улучшению товара. Система показывает динамику оценок и выявляет скрытые тренды.

Технологический стек:
- **Frontend:** HTML, CSS
- **Backend:** JavaScript/FastAPI
- **Database:** MySQL
- **Интеграции:** LLM API (нейронка mistral)
 
## MVP
- Регистрация и вход через Telegram и выход из системы
- Добавление товара по ссылке 
- Парсинг отзывов,их анализ и генерация рекомендаций через LLM API
- Личный кабинет пользователя
- Детальная страница анализа с рекомендациями и статистикой
- Просмотр ранее проанализированных продуктов.
- Сравнение выбранных анализов


## Метрики успеха продукта 
**Производительность:**
- Среднее время ответа Backend API ≤ 2 секунд (без учёта внешних API)
- 95-й перцентиль времени ответа ≤ 3 секунд
- Время загрузки личного кабинета ≤ 2 секунд
- Среднее время анализа товара (парсинг + NLP + LLM) ≤ 60 секунд для 100 отзывов

**Пропускная способность:** поддержка не менее 50 одновременных пользователей, запускающих анализ

**Доступность:** 
- Backend API ≥ 99% в месяц
- Страница аутентификации через Telegram ≥ 99.5%

**Надёжность:** 
- При сбое внешнего сервиса (NLP, LLM) система возвращает сообщение об ошибке ≤ 3 секунд
- Автоматическое восстановление после временной недоступности парсеров

**Использование ресурсов:** 
- Загрузка CPU ≤ 70% при пиковой нагрузке
- Использование памяти ≤ 75% при пиковой нагрузке

**Безопасность:**
- Аутентификация через Telegram OAuth
- Шифрование соединений (HTTPS)
- Валидация данных от Telegram Widget

**Масштабируемость:**
- Возможность горизонтального масштабирования Backend API
- Кеширование отчетов в Redis

# Pain Points 
- Ручной анализ отзывов субъективен и занимает много времени
- Стандартные рейтинги маркетплейсов, выраженные лишь числовыми оценками, не отражают реальных причин недовольства покупателей.
- Неочевидно, какие действия предпринять на основе отзывов для улучшения бизнеса
- Задержка в реакции на негативные отзывы ведёт к потерям продаж и репутации

## Use Cases

- **Регистрация через Telegram.** Новый пользователь регистрируется в системе с помощью Telegram аккаунта через Telegram Widget. После успешной аутентификации создается профиль пользователя и предоставляется доступ к личному кабинету.
- **Вход через Telegram.** Существующий пользователь входит в систему с помощью Telegram аккаунта через Telegram Widget. После успешной аутентификации пользователь получает доступ к личному кабинету с историей анализов.
- **Выход из системы.** Аутентифицированный пользователь выходит из системы, завершая текущую сессию. После выхода пользователь перенаправляется на главную страницу и теряет доступ к функциям личного кабинета.
- **Первый анализ (добавление нового продукта).** Пользователь впервые добавляет товар для анализа путем ввода ссылки на карточку товара с маркетплейса. Система парсит отзывы, анализирует их с помощью ИИ и сохраняет результат в профиле пользователя.
- **Просмотр ранее проанализированных продуктов.** Пользователь просматривает список всех ранее проанализированных товаров в разделе "Мои товары". Каждый товар представлен в виде иконки с краткой информацией о последнем анализе.
- **Просмотр конкретного продукта.** Пользователь просматривает детальную информацию по конкретному товару, включая историю анализов, текущую статистику отзывов, графики и ключевые метрики.
- **Запустить новый анализ по датам.** Пользователь запускает новый анализ существующего товара за выбранный временной период. Система парсит только новые отзывы, появившиеся с момента последнего анализа, и обновляет статистику товара.
- **Сравнить выбранные анализы.** Пользователь, находясь на странице товара, выбирает несколько предыдущих анализов из истории и запускает их сравнение. Система генерирует сводный отчет, визуализирующий ключевые метрики и динамику изменений между выбранными периодами.
  
# Value Proposition (Уникальная ценность продукта)
Собирает и анализирует отзывы с маркетплейсов, чтобы быстро найти проблемы в продукте, которые мешают продажам, и предлагает конкретные улучшения. Помогает бизнесу сократить отток клиентов, повысить рейтинг товара и быстрее принимать решения на основе реальных данных.

# North Star Metric (Главная метрика успеха)
- **Метрика:** Снижение доли негативных отзывов у пользователей относительно исходного уровня.
- **Целевое значение:** ≥60% пользователей, внедривших рекомендации, достигают снижения негатива на ≥20% за 90 дней.
- **Измерение:** Доля негативных отзывов = (Количество отзывов с оценкой 1-2) / (Общее количество отзывов) × 100%; Снижение = (Исходный доля негативных отзывов - доля негативных отзывов через 90дней)
