# 2 лабораторная — Требования

## Выбор типов моделей

### Mistral Small 3 — LLM
**Параметры:** 24B  
**Точность:** 81% на MMLU  
**Лицензия:** Apache 2.0  
**Размер модели:** ~12.8 GB (MXFP4)  
**Поддержка:** Hugging Face, Ollama, Together AI, Fireworks AI  
**Лёгкость развертывания:** подходит для локального использования (16–32 ГБ RAM)

**Плюсы:**
- Высокая производительность при меньших ресурсах  
- Быстрое время отклика (≈150 токенов/с)  
- Подходит для локального развёртывания  
- Поддержка длинных контекстов (до 32 768 токенов)

**Минусы:**
- Уступает в сложных логических задачах  
- Требует настройки под специфические задачи  


### Sentence-BERT (sBERT) — embeddings
**Тип:** open-source, PyTorch / Transformers  
**Размер векторов:** 768 или 1024 (в зависимости от модели)

**Плюсы:**
- Локальное развёртывание (сервер или мощный ПК)  
- Бесплатно, множество предобученных моделей (multilingual, domain-specific)  
- Подходит для кластеризации и семантического поиска по отзывам  

**Минусы:**
- Медленнее, чем оптимизированные API embeddings  
- Требует GPU для обработки больших объёмов  


## Требования к производительности (Latency, Throughput)

**Допустимая задержка (latency):** 5–10 минут  

> Причина: анализ десятков тысяч отзывов (10–50 МБ текста).  
> Включает эмбеддинг, кластеризацию и вызовы LLM — все операции ресурсоёмкие.  
> Пользователь понимает, что это аналитика, а не чат-ответ.

| Сценарий | Объём данных | Целевая Latency | Комментарий |
|-----------|---------------|-----------------|--------------|
| Анализ 100 отзывов | Малый | ≤ 30 с | Мгновенный результат |
| Анализ 1 000 отзывов | Средний | ≤ 2 мин | Приемлемо для оперативного анализа |
| Анализ 10 000–20 000 отзывов | Большой | ≤ 5–10 мин | Нормально для отчёта «по запросу» |
| Повторный просмотр отчёта | — | ≤ 3 с | Должно открываться мгновенно (кэш) |

**Пропускная способность:**  
200–500 отзывов в минуту при использовании Mistral Small 3 + Sentence-BERT.


## Метрики качества

Метрики: **Accuracy**, **Precision**, **Recall**, **F1-score**

| Метрика | Описание | Интерпретация |
|----------|-----------|----------------|
| Accuracy | Доля правильно классифицированных отзывов | Общая точность |
| Precision | Из всех «положительных» — доля действительно положительных | Чистота предсказаний |
| Recall | Из всех реальных положительных — сколько найдено | Полнота анализа |
| F1-score | Гармоническое среднее Precision и Recall | Баланс полноты и точности |

**Целевые значения:**  
- Accuracy ≥ 0.85  
- F1-score ≥ 0.80  


### Human Evaluation
**Где используется:** финальная оценка удобства и осмысленности отчётов.  
**Как проводится:** эксперт оценивает 10–20 отчётов по критериям:

| Критерий | Шкала | Описание |
|-----------|--------|-----------|
| Полезность | 1–5 | Насколько помогает понять проблему |
| Читаемость | 1–5 | Ясность и структура текста |
| Осмысленность | 1–5 | Логичность выводов, отсутствие галлюцинаций |

**Целевые значения:** средний балл ≥ 4.0 по всем критериям.


## Ограничения (Память, Стоимость, Приватность)

### 1. Память
- Mistral Small 3 должен выполняться в пределах **16 ГБ VRAM** или **32 ГБ RAM**.  
- Для 20 000 отзывов использовать **батчи 512–1024**.

### 2. Стоимость
- Используются только **open-source** модели и инструменты.  
- Возможность запуска на одном **GPU среднего уровня** или **локально на CPU**.  
- Без платных облачных API.

### 3. Приватность
- Все данные **анонимизируются**, без персональной информации.  
- Передача данных — только через **HTTPS** или локальные соединения.  
- **Никаких внешних сервисов**, если нет гарантии безопасности.
